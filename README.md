A pi-web fork that automatically follows updates to Pi harness, powered by Manus Cue Agent. Not affiliated with pi or manus. Checked every 30 minutes, implemented with minimal coding.

## Clone & run

Requires Node.js `>=22.19.0`.

```sh
git clone https://github.com/YUGOROU/pi-web-follow-pi.git
cd pi-web-follow-pi
npm install
npm run dev
```
